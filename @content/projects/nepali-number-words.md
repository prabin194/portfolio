# Nepali Number Words

A lightweight, framework-independent TypeScript library for converting numbers and monetary amounts to Nepali words.

## Features

- Number to Words: Convert integers to Nepali words
- Amount to Words: Convert monetary amounts to Nepali currency words
- Words to Number: Convert Nepali words back to numbers (experimental)
- Devanagari Digits: Convert Arabic numerals to Devanagari
- Currency Formatting: Format amounts with Indian/Nepali grouping
- Framework Agnostic: Works with React, Vue, Node.js, Next.js, Nuxt

## Installation

```bash
npm install nepali-number-words
```
